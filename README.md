## AI 참모 · 2026-09-29

**작전 지도 → 리서치 → 종목 참모**에서 핵심 브리핑·가설 반박·작전 검토를 요청합니다. **연결 설정**에서 OpenAI API 키와 모델을 설정하며, 키는 현재 Windows 사용자 DPAPI로 암호화해 저장합니다. 기본 모델은 `gpt-5.4-mini`입니다. 키 없이도 **지표만 계산**으로 기존 Phalanx Python 엔진의 수익률·변동성·낙폭과 재무 지표를 확인할 수 있습니다.

근거 버튼은 기준일·출처와 해당 차트·재무·노트로 연결합니다. 참모 내용을 기존 명령서 근거/위험에 덧붙이고 저장하며, 종목·자료·노트·계획 변경 시 이전 답변을 초기화합니다. AI 해석과 수치 계산·자료 부족을 구분합니다. 사용자 설정 후 실제 OpenAI 응답을 확인했으며 포트폴리오 검토도 합성 입력으로 실제 응답을 검증했습니다.

## 실계좌 · 포트폴리오 작전 시뮬레이터 · 2026-09-29

사령부 작전 지도를 열면 기존 WSL Python 서비스를 통해 계좌와 전체 보유종목을 조회합니다. 예수금은 증권사 값 그대로 표시하며 주문가능금액으로 간주하지 않습니다. 시뮬레이션에는 별도 현금 가정(기본 0원)을 입력합니다.

목표 비중 → **변경안 계산** → 선택적으로 **참모 검토** → **명령서에 적용** 순서입니다. 기존 Python 자산·현금 배분 함수를 사용하며, 매매 수량은 1주 단위로 내리고 잔여 현금을 대사합니다. 현재 보유량 유지와 전량 현금은 별도 정확 계산입니다. 수수료·세금·체결 오차·결제 지연은 제외합니다. AI에는 종목명·코드·비중과 계산 가정만 보내고 금액·수량·계좌번호는 보내지 않습니다.

새 명령서는 실계좌 기반 변경안에서만 작성합니다. 기존에 봉인한 일지는 출처와 함께 읽을 수 있습니다. 작전 일지에는 기록의 출처와 조회 시각, 현금 가정을 함께 남깁니다. **실제 주문을 전송하지 않습니다.** [사용법·계산 범위·검증](docs/PORTFOLIO_SIMULATOR.md)을 참고하세요.

## 관심종목과 노트 자동 저장

시장 화면의 **★ 관심 / ☆ 추가**로 관심종목을 편집합니다. 보유종목은 관심 등록 여부와 관계없이 표시합니다. 해제한 비보유 종목은 **시장 전체 검색**에서 다시 찾습니다. 관심 등록한 새 종목의 이름·코드는 다음 실행에도 복원합니다. 관심 해제는 해당 종목의 노트를 지우지 않습니다.

리서치 노트는 입력 후 약 0.5초에 자동 저장하며, 화면 이동·대시보드 닫기·정상 종료 전에 대기 입력을 반영합니다. 하단 저장 상태와 실패 시 **저장 재시도**를 확인하세요. 빈 관심목록과 지운 노트도 그대로 복원됩니다.

저장 위치는 `user://investment_workspace.json`입니다. Windows 기본 경로는 `%APPDATA%\Godot\app_userdata\Phalanx Headquarters`이며 하단 저장 상태의 툴팁에서도 실제 경로를 확인할 수 있습니다. 이전 정상본은 `.bak`에 보관합니다. 관심종목·노트에 더해 목표 비중·명령서 초안·작전 일지도 재실행 후 복원합니다. 기존 v1/v2 저장본은 읽을 때 메모리에서 v3로 옮기고, 첫 저장 시 원본을 백업합니다.

## 관심그룹과 종목표 · v1

시장 왼쪽 **관심그룹 · 종목표**에서 전체 관심·보유·사용자 그룹을 전환합니다. 그룹 생성·이름 변경·삭제와 선택 종목의 여러 그룹 편입을 지원합니다. 그룹은 이름과 별개인 고유 ID로 저장하며, 그룹에서 종목을 빼거나 그룹을 삭제해도 전체 관심과 노트는 유지됩니다. 그룹 편입 시 전체 관심에도 추가합니다. 시장의 **★ 관심**을 해제하면 전체 관심과 모든 그룹에서 빠지며 노트는 보존됩니다.

종목표의 종목명·코드·시장·종류·보유 여부·조회 상태 열 머리글을 누르면 오름차순/내림차순을 전환합니다. 정렬 후에도 선택은 종목코드 기준으로 유지됩니다. 행 선택은 기존 차트·리서치·참모 대상을 바꾸며, **차트 보기** 또는 **리서치·참모**로 이동할 수 있습니다. 유료 AI는 기존 요청 버튼에서만 실행합니다. 표에는 가격을 표시하지 않으며 확인되지 않은 시장·종류는 `—`로 표시합니다.

그룹·선택 그룹·정렬 상태는 기존 자동 저장 흐름으로 복원합니다. 그룹은 최대 32개, 이름은 40자, 전체 관심은 기존과 같은 1,000개 한도입니다. [구현·검증·직접 확인 순서](docs/WATCHLIST_GROUPS_TABLE_VALIDATION.md)를 참고하세요.

## 시장 전체 종목 검색 · 2026-09-30

시장 왼쪽의 **시장 전체 검색**에서 종목명 또는 코드로 미보유 종목을 찾고 **관심 추가 · 차트 보기**를 누릅니다. ETF와 우선주도 검색에 포함됩니다. 결과는 최대 30건씩 표시하며 시장·종류·출처·수집 시각을 확인할 수 있습니다. 첫 실행에는 WSL의 기존 discovery 저장 목록을 가져오고, 이후 검색은 Godot의 저장 목록에서 수행합니다. **목록 갱신**만 새 discovery 수집을 요청합니다. 최초 자료 없음, 검색 결과 0건, 갱신 실패를 구분하고 갱신에 실패하면 이전 목록과 시각을 유지합니다.

식별자가 충돌하거나 현재 워크스페이스 저장 형식에 맞지 않는 종목은 검색 결과에 남기되 등록을 막고 사유를 표시합니다. 기존 KIS 일봉 경로가 지원하지 않는 코드도 검색 결과에서 조회 범위를 안내합니다. 선택한 종목은 기존 시장 차트·리서치·참모 대상으로 이어지며, 참모 AI는 별도 요청 버튼을 눌러야 실행됩니다. 미보유 종목의 배분 시뮬레이터 편입은 아직 지원하지 않습니다. 목록과 사용자 관심·노트는 서로 다른 저장 파일이며, 테스트에서는 `PHALANX_CATALOG_CACHE`와 `PHALANX_WORKSPACE_PATH`를 격리합니다.

## 작전 명령서와 작전 일지 · 2026-09-29

사령부 지도 → 포트폴리오의 **변경안 계산 → 명령서에 적용**에서 작전 이름, 판단 근거, 주요 위험을 적습니다. **명령서 봉인 · 기록**을 누르면 확정 시점의 종목·조회 가격·보유 수량·목표 비중·모의 매매 수량·계획 후 현금과 작성 시각을 저장합니다. 저장이 성공해야 기록 완료 인장이 찍힙니다. 이후 비중이나 초안을 바꿔도 과거 기록은 바뀌지 않습니다.

사령부 테이블 왼쪽 두루마리 또는 **◆ 작전 일지** 표시를 클릭하면 날짜별 기록이 최신순으로 펼쳐집니다. 기록은 읽기 전용이며 현재 계획에 자동 적용되지 않습니다. Esc는 명령서 → 분석 화면/일지 → 사령부 순서로 닫습니다. 기록은 최대 200건, 판단 근거와 위험은 각각 2,000자입니다. 저장 실패·다른 창과의 저장 충돌은 화면에 표시하고 기존 기록과 작성 중인 내용을 보존합니다.

이 기능은 **실계좌 조회를 바탕으로 한 모의 계획을 기록**합니다. 기록마다 출처를 표시하며, 실제 주문·체결·계좌 잔고 변경 기능은 없습니다.

## 조작과 화면 흐름

1. **야영지:** 이동 가능한 지면을 왼쪽 클릭해 목적지를 지정합니다. 사령부 입구에 접근한 뒤 표시되는 상호작용으로 입장합니다. 카메라는 정해진 쿼터뷰이며 자유 회전하지 않습니다.
2. **사령부:** 고정 구도에서 지도/작전 테이블을 클릭해 대시보드를 엽니다. 왼쪽 두루마리의 **작전 일지**는 지난 명령서를 엽니다. WASD 보행·마우스 시선 회전·마우스 캡처·중앙 조준점·조준 후 E 입력을 사용하지 않습니다.
3. **대시보드:** 종목 검색, 기간 선택, 차트, 목표 비중과 모의 매매계획을 조작합니다. 대시보드를 닫으면 동일한 사령부 구도로 돌아옵니다.
4. **복귀:** 사령부의 **야영지로** 조작으로 나갑니다. 야영지 캐릭터는 입구 부근의 안전한 위치로 복원됩니다.

Esc는 열린 모의 계획 팝업을 먼저 닫고, 다음 입력으로 대시보드를 닫습니다. 팝업과 대시보드가 없는 사령부에서는 Esc 또는 **야영지로** 버튼으로 나갑니다. 야영지의 Esc는 화면을 바꾸지 않습니다. 상·하단 UI 클릭은 뒤쪽 지도나 야영지 이동에 전달되지 않습니다.

대시보드는 실행 중 재사용하므로 종목 선택을 유지하며, 명령서에 적용한 변경안은 재실행 후에도 복원됩니다. 목표 비중 합계가 100%를 넘으면 계산을 거부하고 명령서 적용을 막습니다. 화면보다 긴 내용은 세로로 스크롤하며, 닫기 조작은 위에 유지합니다.

화면에 보이는 사령부 주변의 작은 구역을 우선합니다. 붉은 군막, 따뜻한 역광, 깊은 내부 그림자, 지도 중심 구도, 낡은 목재와 부분적인 금속 반사, 비대칭 소품 배치가 미술 기준입니다. 고정시점 배경·2.5D 요소를 사용할 수 있으며 배경의 종횡비, 이동 캐릭터의 접지/가림, 클릭 영역 정렬을 함께 관리합니다.

야영지·사령부는 이전 작업의 `image_gen` 배경을 그대로 사용하며, 가림 마스크·불꽃·먼지를 결합한 2.5D 구성입니다. **플레이어 한 명만 코드로 제작한 관절형 3D 모델**을 별도 투명 뷰포트에서 38도 사선으로 렌더해 배경에 합성합니다. 야영지 전체를 3D로 재구축한 것이 아닙니다. 파일별 제작 경위는 [시각 에셋 기록](assets/art/PROVENANCE.md)에 있습니다.

캐릭터는 네 방향을 포함한 연속 방향의 대기·보행 포즈를 사용합니다. 실제 이동 거리에 보행 위상을 맞추고, 지지 중인 발의 지면 기준점과 다리 IK, 팔·망토의 움직임을 함께 계산합니다. 정지하면 마지막 방향으로 대기하며 방향 전환과 출발·도착을 완화합니다. 깊이 정렬·원근 크기·접촉 그림자는 발 위치를 기준으로 관리합니다. 기존 단일 포즈 `commander.png`는 이전 작업 보존용이며 현재 런타임 캐릭터로 사용하지 않습니다.

나무와 상자 일부의 가림 윤곽을 별도 모듈로 관리합니다. 나뭇잎 사이 흙색 부분은 원본 색을 이용한 알파 처리로 열어 두며, 원본 배경과 UV 좌표를 공유합니다. 전체 식생을 다시 분리한 것은 아니며 색 분리 마스크와 캐릭터 합성의 미술적 한계는 실제 실행 기록에서 평가합니다.

기존 `scenes/command_camp.tscn`과 1인칭 관련 `camp_player.gd`, `table_interaction.gd`, 절차적 3D 미술 파일은 이전 구현 자료입니다. 현재 시작 흐름이 그 입력 방식에 의존하도록 되돌리지 않습니다. 전투·훈련·복잡한 NPC 대화는 현재 범위가 아닙니다. 투자 기능은 위의 최신 개발 초점을 따릅니다.

## 검증

최신 실제 종목 분석 검증은 [RESEARCH_DATA_VALIDATION.md](docs/RESEARCH_DATA_VALIDATION.md)를 기준으로 합니다. [TERMINAL_UI_VALIDATION.md](docs/TERMINAL_UI_VALIDATION.md)는 앞선 가상 데이터 UI 단계의 기록입니다. 캐릭터 보행·합성의 실행 증거와 미술 평가는 [캐릭터 움직임 검증 기록](docs/AVATAR_MOTION_VALIDATION.md)을 기준으로 확인합니다. [쿼터뷰 전환 검증 기록](docs/QUARTER_VIEW_VALIDATION.md)은 단일 포즈 캐릭터를 사용했던 이전 단계의 기록입니다. 자동/합성 입력, 운영체제 창 조작, 사람이 직접 수행한 검증을 구분하며, 이전 테스트 PASS를 새 캐릭터의 검증으로 대신하지 않습니다.

기존 데이터·대시보드 회귀, 새 화면 흐름과 기본 실행 확인 명령은 다음과 같습니다.

```powershell
$godot = 'C:\Users\hanso\Tools\Godot\Godot_v4.7.2-stable_win64_console.exe'
& $godot --headless --path . --script res://tests/smoke_test.gd
& $godot --headless --path . --script res://tests/terminal_workspace_test.gd
& $godot --headless --path . --script res://tests/workspace_persistence_test.gd
& $godot --headless --path . --script res://tests/quarter_flow_test.gd
& $godot --headless --path . --quit-after 60
```

실제 GPU 렌더와 두 해상도 스크린샷을 남기는 검증에는 `--headless`를 붙이지 않습니다. 아래는 Godot 안에 합성 입력을 주입하는 테스트이며 운영체제 창 조작이나 사람의 직접 조작을 뜻하지 않습니다.

```powershell
$review = Join-Path $env:TEMP 'phalanx-quarter-review'
& $godot --path . --script res://tests/quarter_flow_test.gd -- $review
```

1280×720과 1440×960에서 야영지 이동 → 사령부 입장 → 테이블 클릭 → 대시보드 → 사령부 복귀 → 야영지 복귀를 확인합니다. 배경 비율, 클릭 위치, 장애물 회피/가림, 팝업 우선 Esc, UI 가독성, 차트와 가상 데이터 표시도 검사합니다. 기능 통과와 시안 대비 미술 품질은 별도로 평가합니다.

배경의 주요 그늘 위치에 따라 캐릭터의 직사광·주변광·드리운 그림자가 변한다. 밝은 지면으로 나오면 원래 조명으로 돌아오고 발밑 접촉 그림자는 유지한다. 원본 배경을 바꾸면 `camp_light_field.gd`의 구역도 다시 맞춰야 한다. 작은 잎 그림자를 몸에 따로 투영하는 방식은 아니다.
