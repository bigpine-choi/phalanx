# Phalanx · 작전 명령서와 작전 일지

2026-09-29 실제 Godot 프로젝트에 반영했습니다.

실계좌 기반 변경안은 [포트폴리오 시뮬레이터 안내](PORTFOLIO_SIMULATOR.md)를 참고합니다. 아래는 샘플 계좌 명령서 흐름과 당시 검증 기록입니다.

## 사용 순서

1. 야영지에서 사령부로 들어갑니다.
2. 작전 지도를 열고 시장의 **비중 계획** 또는 포트폴리오의 **샘플 계좌 보기**에서 목표 비중을 조정합니다.
3. **작전 명령서 작성 →**을 누릅니다.
4. 작전 이름·판단 근거·주요 위험을 적고 **명령서 봉인 · 기록**을 누릅니다. 긴 문서는 세로로 스크롤합니다.
5. 저장이 성공하면 인장이 찍힙니다. 사령부 왼쪽 두루마리 또는 **◆ 작전 일지** 표시를 클릭하면 지난 기록을 읽을 수 있습니다.

목표 비중과 미완성 초안은 자동 저장됩니다. 지난 기록에는 확정 당시의 샘플 가격, 보유 수량, 목표 비중, 모의 매매 수량, 계획 후 현금, 근거와 위험, 작성 시각이 보관됩니다. 이후 계획을 수정해도 이전 기록은 바뀌지 않습니다.

Esc는 명령서, 분석 화면/일지, 사령부 순서로 닫습니다. 기록은 최대 200건이며 판단 근거와 위험은 각각 2,000자까지입니다. 실제 주문이나 계좌 잔고 변경은 하지 않는 모의 계획 기록 기능입니다.

## 검증

- 명령서 저장·중복 방지·기록 불변성·이전 저장 형식 보존·충돌/실패/재시도: 37개 검사 통과.
- 두루마리/지도 클릭, 읽기 전용 기록, 960×680·1280×720·1440×960·2160×1440 배치와 Esc: 48개 검사 통과.
- 기존 저장 45개, 분석 화면 43개, 야영지/사령부 흐름 204개 검사 통과. 합계 377개.
- 별도 Godot 프로세스를 종료하고 새로 실행해 목표 비중·초안·봉인한 기록 복원 확인.
- GPU 렌더로 화면 검수. Windows Godot 창에서 실제 마우스·키보드로 작전명/근거/위험 입력 → 봉인 → Esc 복귀 → 두루마리 클릭 → 기록 열람 → 창 최대화 확인.
- 검증용 기록은 별도 임시 저장본을 사용했습니다. 화면의 ‘예시 작전’과 ‘검증용 작전’은 테스트 데이터입니다.
