## 검증 방식과 결과

검증 환경: Windows, Godot 4.7.2 stable, D3D12/Forward+, NVIDIA GeForce RTX 5070 Ti Laptop GPU. OS 화면 배율 때문에 컴퓨터 사용 도구의 창 이미지는 실제 게임 뷰포트보다 작게 캡처된다. `camp/headquarters/dashboard-해상도.png`는 Godot 뷰포트 원본 크기의 별도 GPU 캡처다.

### 컴퓨터 사용 도구로 실제 창 조작

`computer-use`의 `@oai/sky`를 통해 대상 Godot 창을 관찰하고 OS 클릭·키 입력을 보냈다. 각 단계의 실행 화면을 직접 확인했다. 이는 사람이 마우스와 키보드를 직접 조작한 검증과 구분한다.

GPU 합성 입력에서 실제 OS 포인터와 주입한 좌표가 달라지는 문제는 실내 상호작용이 입력 이벤트 좌표를 직접 사용하도록 해결했다. 최종 수정 후 1280×720 실제 창에서 하단 안내 클릭 차단, 입구 접근/진입, 지도 호버 윤곽과 클릭, 분석 화면 스크롤·종목/차트 기간 변경, Esc 복귀, 야영지로 버튼과 위치 복원을 재확인했다. 최종 GPU 합성 검사는 두 해상도 모두 다시 실행했다.

## 미술 평가 — 기능 통과와 별도

사용자가 제공한 세 이미지를 직접 열어 검토했다. 이번 결과는 절차적 상자와 균일 재질을 소폭 조정한 결과가 아니라, 고정 구도를 전제로 새로 생성한 배경과 분리된 캐릭터/가림/효과를 조합한 2.5D 장면이다.

시안에 가까워진 부분:

- 높은 사선 야영지, 진홍·크림 군막, 식생·항아리·방패·상자가 둘러싼 작은 마당과 명확한 입구.
- 실내의 깊은 버건디 천막 그림자와 입구의 따뜻한 역광. 전경 지도 중심으로 구도를 고정해 테이블 다리가 화면을 차지하던 구성을 해소했다.
- 천 처짐·장식, 낡은 목재, 투구/잔의 부분 금속 반사, 두루마리·문서·무기의 비대칭 배치와 원경 안개가 배경에 표현된다.
- 화면 비율을 유지하고 이미지와 클릭/이동/가림 좌표에 같은 변환을 사용한다. 제한된 불꽃·먼지 움직임을 추가했다.

여전히 부족한 부분:

- 시안 수준의 완성형 게임 미술을 달성했다고 평가하지 않는다. 지휘관은 단일 방향 스프라이트의 좌우 반전과 작은 흔들림이므로 실제 다방향 보행보다 미끄러지는 느낌이 남는다.
- 조명·천·소품·원경은 이미지에 구워진 표현이다. 실제 동적 그림자나 천 물리, 다양한 시점의 입체 장면이 아니다. 실내 참모 인물은 구현하지 않았다.
- 전경은 배경 픽셀을 재사용하는 다각형 마스크다. 나뭇잎 사이의 정교한 알파 분리와 모든 물체의 세밀한 가림은 후속 미술 작업이 필요하다.
- 불꽃은 간단한 런타임 도형 효과여서 배경의 사실적인 재질과 표현 차이가 남는다. 깃발 애니메이션은 없다.
- 배경 원본은 1672×941이며 큰 화면에서는 확대 한계가 있다. 분석 화면은 기존 기능/차트가 유지된 UI이고, 참조의 인물 배치나 장식 UI를 그대로 재현하지 않았다.

외부 에셋 다운로드·유료 구매·계정 생성·프로그램 설치는 하지 않았다. 생성 파일과 사용 방식은 [에셋 출처 기록](../assets/art/PROVENANCE.md)에 명시했다.
