같은 PC에서 측정한 메인 루프 프레임 간격 중앙값은 1280×720에서 1.939→2.648ms, 1440×960에서 1.327→2.396ms였다. VSync를 끈 검수 프로세스의 짧은 측정이며 순수 GPU 시간이나 지속 FPS, 물리 입력 지연으로 해석하지 않는다.

샌드박스 실행에는 기존 인증서 저장소 읽기 및 일부 캐시 저장 환경 오류가 있었다. 실제 사용자 데스크톱 GUI 로그에는 해당 오류가 없었고, 최종 스크립트·셰이더 파싱 오류도 없었다. 보안 설정을 바꾸지 않았다.

### 남은 수동 확인 — 아직 완료로 기록하지 않음

1. **WASD 지속 입력:** 실제 키를 길게 눌러 테이블을 한 바퀴 돌고 입구 경사로를 왕복한다. 키를 놓으면 즉시 멈추고, 통로에서 끼거나 물체·바닥을 통과하지 않아야 한다.
2. **실제 마우스 회전:** 캡처 상태에서 좌우 회전과 위아래 제한을 확인한다. 시점이 뒤집히거나 캡처 재개 시 크게 튀지 않아야 한다.
3. **이동키를 누른 채 Alt+Tab:** 포커스를 잃으면 입력이 중단되어야 한다. 게임으로 돌아와 클릭하기 전까지 정지하고, 클릭 후에도 이전 키 상태가 남아 자동으로 움직이지 않아야 한다. 새 입력으로 정상 재개하는지 확인한다.

자동 합성 이벤트 통과와 단순 창 포커스 전환 확인은 위 세 항목의 사용자 직접 확인을 대신하지 않는다.

## 다음 작업 — 테이블·지도 그래픽 개선

다음 구현의 우선순위는 테이블과 지도다. 이번 저장 작업에서는 착수하지 않는다.

1. 두 시안과 현재 시작/근접/측면 화면을 나란히 비교해 테이블 앞판·다리 비중, 지도 면적과 읽기 쉬운 시선 각도를 다시 평가한다. 사람 눈높이와 순환 통로, E 거리·가림 판정을 유지한다.
2. 테이블의 두꺼운 상판과 받침을 더 설득력 있게 다듬는다. 모서리 마모·접합부·목재 결 방향·거칠기·절제된 청동 장식을 개선하며, 형태가 필요한 부분을 표면 노이즈만으로 대체하지 않는다.
3. 지도의 종이 질감·은은한 얼룩·가장자리, 해안과 지형의 세부 형태, 행군 경로와 군단 표식의 가독성을 개선한다. 과한 광택·장식으로 읽기 어려워지지 않게 한다.
4. 동일 해상도와 구도로 시작·근접·앞뒤·양옆을 실제 렌더링한다. 뒷면·접지·겹침·재질 반복·빛 경계를 확인하고 관련 충돌/입력 회귀 테스트와 장면 비용을 비교한다.

시안의 사실적인 조각·천 주름·암석/식생 밀도·불꽃·연기에는 아직 차이가 있다. 미술 완성도를 테스트 통과로 대체하지 않는다. 참모/NPC, 패스 C 대시보드 미술 통일, Python 연결까지 임의로 확대하지 않는다.
