# 관심그룹 시세판과 차트 탐색 v1

기준일: 2026-09-30. 기준 커밋 `972a06f`, 개발 브랜치 `feature/watchlist-quotes-chart-v1`.

## 사용 범위

관심그룹 표에 현재가·출처·수신 시각(KST)·시세 상태를 추가했다. 기존 종목명·코드·시장·종류·보유·일봉 상태도 유지한다. 가격은 숫자로 정렬하고 미조회 값은 `—`로 표시하며 양방향 정렬에서 마지막에 둔다. 정렬과 비동기 갱신 뒤에도 선택은 코드로 연결된다.

**표시 종목 시세 갱신 · 최대 20**은 현재 그룹·검색·정렬 결과의 첫 20개 적격 코드를 고정해 순차 조회한다. 화면을 아래로 스크롤하는 것만으로 요청 대상은 바뀌지 않는다. 다른 종목을 갱신하려면 그룹·검색·정렬을 조정한다. 숫자 6자리 외 코드는 미지원으로 표시하고 식별자 충돌은 조회를 막는다.

리서치 버튼과 표가 NH 게이트웨이 하나를 공유한다. 동시에 프로세스 하나, 요청 시작 사이 최소 300ms, 중복 요청 억제, 코드·요청 토큰 확인을 적용했다. 취소·그룹 변경·표 닫기는 대기 큐를 비우며 이미 진행 중인 한 건은 원래 코드에만 반영한다. 자동 주기 갱신과 실시간 구독은 후속 범위다.

실패 시 이전 정상 가격과 수신 시각은 보존한다. 최초 미조회·미지원·조회 중·실패·이전 시세·오프라인·저장 실패를 구분한다. 수신 후 5분을 초과하면 오래된 시세로 표시하며 시간 경과 표시는 추가 네트워크 요청 없이 바뀐다. 수신 시각은 유효 응답을 받은 뒤 브리지가 기록하는 시각이며 거래소 체결 시각을 뜻하지 않는다.

## 차트 조작

- 휠 위/아래: 커서 위치를 기준으로 확대/축소. 기본 최소 8봉, 최대 저장된 전체 일봉.
- 왼쪽 드래그: 확대된 창을 과거·최근 구간으로 이동. 데이터 양끝에서 멈춘다.
- 더블클릭·1개월/3개월/1년 버튼: 선택한 기간의 최근 구간으로 복원.
- 같은 종목 재선택·같은 일봉·캔들/라인 전환은 탐색 상태 유지. 다른 종목 선택은 초기화.
- 이동 구간의 평균선은 전체 일봉의 절대 위치로 계산한다. 확대·이동은 추가 조회나 AI 요청을 하지 않는다.
- 차트 위 휠은 부모 ScrollContainer로 전파하지 않고 차트 밖 스크롤은 유지한다.

## 저장과 변경 경계

workspace 스키마는 v3 그대로이며 허용 정렬 열만 확장했다. 그룹·선택 그룹·가격 정렬·노트·명령서·일지는 기존 저장 경로를 따른다. NH 가격은 workspace와 분리된 `quotes.json`에 검증 후 원자적으로 교체한다. 최대 1,000개를 보관하고 한도 도달 시 가장 오래된 시세부터 정리한다. 가격 캐시 정리는 관심 등록·그룹·노트에 영향을 주지 않는다.

`PHALANX_NH_QUOTE_CACHE`는 캐시 **디렉터리**다. 미지정 시 `PHALANX_RESEARCH_CACHE/nh-quotes`, 두 환경변수 모두 없으면 `user://research_cache/nh-quotes`를 사용한다. 저장 캐시는 재실행 시 이전 수신 자료로 복원하고 손상·중복 코드·미래 시각 자료를 거부한다. `PHALANX_NH_OFFLINE=1`은 NH 네트워크 요청을 차단한다.

기존 미커밋 참모 변경 `advisor_panel.gd`, `market_catalog_ui_test.gd`는 원래 해시 그대로 보존했다. 기존 NH 작업을 이번 범위에서 확장했다. 사용자 프로필·인증정보·실제 계좌·시세 캐시·검수 로그는 저장소에 추가하지 않는다.

### 실제 NH 조회

초기 개발에서는 `nhplug_live_probe.gd`로 `005930` 1건을 조회했다(23:12:21 KST). 최종 검수에서는 아래 3종목 그룹의 **표시 종목 시세 갱신을 한 번만** 눌렀다. F5 기본 야영지 씬 → 사령부 입장 → 작전 지도 → 관심그룹 → 공유 게이트웨이 → WSL Python → NH SDK의 실제 경로이며 성공 3건·실패 0건이었다.

| 종목 | 종류 | NH 관측 가격 | 수신 완료 시각(KST) |
| --- | --- | ---: | --- |
| 삼성전자 `005930` | 보통주 | 269,500원 | 2026-09-30 23:27:58 |
| 삼성전자우 `005935` | 우선주 | 196,400원 | 2026-09-30 23:27:58 |
| KODEX 200 `069500` | ETF | 109,545원 | 2026-09-30 23:27:57 |

표의 세 값·시각을 격리 캐시 `quotes.json`과 대조했다. `005935` 선택 후 리서치의 NH 가격·시각도 일치했다. 이 값은 검증 당시 관측이며 최신 시세를 보장하는 고정 예시가 아니다. Python은 SDK 응답 및 가격 검증 뒤 시계를 읽는다. 순서 검사는 응답→수신 시각 기록을 검증하므로 ‘수신 시각’은 요청 시작 시각이 아니다.

실제 계좌·KIS 일봉·discovery·유료 AI는 오프라인으로 두었다. 인증정보는 WSL SDK 설정에 두고 결과에는 공개 가격과 출처·수신 시각만 전달했다. 부분 실패는 실제 장애를 유발하지 않고 별도의 가짜 연결에서 성공 2·실패 1로 검증했다. 실패한 `005380`의 이전 333,000원·원래 수신 시각·`갱신 실패 · 이전 시세`가 같은 Tree 행에 남았고, 두 성공 가격으로 재정렬되어도 선택 코드가 유지됐다.

### 실제 창 검수

격리된 60종목·241봉 합성 자료로 실제 Windows Godot 창을 조작했다. 1280×720에서 10개 열·가격 정렬·선택 코드 유지·오프라인 갱신 시 가격과 시각 보존을 확인했다. 휠로 66봉→53봉 확대, 드래그로 시작 인덱스 182→168 이동, 축소와 더블클릭으로 최근 66봉 복원을 확인했다.

같은 저장본을 별도 1440×960 프로세스로 열어 가격 정렬과 이전 NH 값·시각 복원을 확인했다. 표에서 KODEX 200을 선택해 리서치·참모의 코드 `069500` 일치를 확인했다. 리서치 차트 휠로 66봉→53봉, 드래그로 시작 인덱스 183→170 이동 중 페이지 스크롤은 0을 유지했고, 차트 밖 휠에서는 페이지 스크롤이 415로 변했다.

최종 검토에서 커밋 대상 복사본을 별도 Godot 에디터로 열고 **F5**를 눌러 1280×720 기본 야영지에서 위 3종목 갱신까지 직접 진행했다. 우선주 `005935`를 선택하고 가격 오름차순·내림차순 정렬 뒤에도 선택을 유지했다. 리서치·참모 대상은 모두 `005935`였다. 합성 241봉을 사용한 리서치 차트는 시작/표시 수 `175/66 → 182/53` 확대, 드래그 `170/53`, 축소 `163/66`, 더블클릭 `175/66` 복원을 확인했다. 기존 1440×960 창 검수는 변경·실패가 없어 반복하지 않았다.

최종 `native1280-complete.log`, `native1440-complete.log`, `f5-1280.log`와 실제 NH·통합 검사 로그에 엔진·스크립트 오류가 없었다. F5의 일봉·목록은 격리 검수 자료이며 실계좌는 비어 있다. 임시 복사본의 읽기 전용 상태 관찰기만 선택 코드·정렬·차트 범위를 기록했고 제품 경로는 바꾸지 않았다. 검수 로그·프로필·시세 캐시·관찰기는 커밋하지 않는다. 실행 옵션 누락·임시 관찰기 준비 중의 실패 로그는 통과 증거에 포함하지 않는다.

### 발견해 수정한 결함

- Godot JSON의 정수형 값이 float로 파싱되는 경우를 검증·정수 변환해 실제 NH 응답을 수용한다.
- 임시 preview 제거 뒤 예전 배열 인덱스로 선택 코드를 읽던 경로를 독립된 차트 선택 코드로 바꿨다.
- 새 카탈로그 충돌이 생기면 NH 값뿐 아니라 이미 표시한 KIS 일봉도 보류하고, 충돌 해소 후 기존 조회 경로로 복구한다.
- 실제 창의 빠른 드래그에서 중간 이동 이벤트가 합쳐져도 버튼을 놓는 최종 위치까지 이동한다.
- 최종 검토에서 카탈로그 충돌 해소가 게이트웨이 상태를 바꾼 뒤 표 행을 다시 계산한다. 바깥 갱신이 이전 `일봉 미지원` 행을 덮어 쓰던 문제를 수정하고 표시 중인 표의 상태 복구 검사를 추가했다.

## 직접 확인 순서

1. 격리 환경으로 Godot 에디터를 실행하고 F5 → 야영지의 사령부 입장 → 작전 지도 → 관심그룹·종목표를 연다. 원하는 그룹·검색 결과에서 **표시 종목 시세 갱신**을 누른다.
2. 출처·수신 시각과 행별 상태를 확인하고 현재가 열을 두 번 눌러 양방향 정렬한다. 선택 코드는 유지돼야 한다.
3. 갱신 중 중단·그룹 변경을 시도한다. 실패·오프라인에서는 이전 가격과 시각이 남아야 한다.
4. 선택 종목의 **차트 보기** 또는 **리서치·참모**로 이동한다. NH 현재가와 KIS 일봉 기준을 구분한다.
5. 차트 위에서 휠·드래그·더블클릭을 조작하고, 차트 밖에서는 페이지 스크롤을 확인한다.
6. 앱을 종료하고 같은 격리 저장본으로 다시 실행해 그룹·정렬·노트와 이전 NH 시세를 확인한다.

검수 창 실행 예: `--resolution 1280x720 --script res://tests/watchlist_quotes_review.gd -- <격리 절대 디렉터리> 1280`. 1440×960에서는 해상도와 마지막 인수를 함께 바꾼다. 이 창의 시세·일봉은 합성 자료이며 NH 네트워크는 꺼져 있다.

F5 준비용 `--headless --script res://tests/watchlist_quotes_f5_fixture.gd -- <새 격리 절대 디렉터리>`는 3종목 그룹·목록·합성 일봉만 만들며 네트워크를 호출하지 않는다. 기존 프로필이 있으면 덮어쓰지 않고 중단한다. 에디터 프로세스에 `PHALANX_WORKSPACE_PATH=<디렉터리>/profile.json`, `PHALANX_CATALOG_CACHE=<디렉터리>/catalog.json`, `PHALANX_RESEARCH_CACHE=<디렉터리>/research`, `PHALANX_NH_QUOTE_CACHE=<디렉터리>/nh`를 지정한다. `PHALANX_ACCOUNT_OFFLINE`, `PHALANX_RESEARCH_OFFLINE`, `PHALANX_ADVISOR_OFFLINE`, `PHALANX_CATALOG_OFFLINE`은 모두 `1`로 두고, NH 실 검증을 의도한 실행에서만 `PHALANX_NH_OFFLINE=0`으로 둔다.

## 남은 범위

자동 갱신·실시간 구독·다종목 실 API 장시간 운용·실제 서비스 장애·다른 PC의 WSL 환경은 검증하지 않았다. 보통주·우선주·ETF는 각 1종목 1회 확인이며 해당 종류 전체의 응답을 보장하지 않는다. 이번 F5 차트는 합성 일봉이므로 KIS 재수집 검증을 뜻하지 않는다. 차트 탐색 상태의 앱 재실행 저장은 이번 범위에 없다. 미보유 종목의 배분 편입과 실제 주문도 후속 범위다.
