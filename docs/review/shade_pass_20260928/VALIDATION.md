# 야영지 그늘 반응·후속 검수 · 2026-09-28

## 결과

배경 그림자 안에서도 캐릭터가 동일한 햇빛을 받던 문제를 수정했다. `camp_light_field.gd`의 배경 좌표 기반 그늘 구역이 캐릭터의 직사광, 주변광 색·세기, 2D 드리운 그림자에 연결된다. 햇빛으로 나오면 원래 조명으로 복구하며 발밑 접촉 그림자는 유지한다. 카메라·배경 PNG·이동 속도·보행·사령부/대시보드 기능은 유지했다.

같은 모델·방향·포즈의 실제 GPU 이미지에서 불투명 픽셀 평균 밝기는 햇빛 0.37648, 그늘 0.26269, 비율 **0.69775**였다. 이는 한 검수 포즈의 결과이며 모든 방향이 같은 비율로 바뀐다는 뜻은 아니다. 숫자뿐 아니라 그늘 안에서 붉은 망토와 리넨 갑옷이 어두워지고 따뜻한 반사가 줄어드는 것을 실제 창에서 확인했다.

자동 검사는 사람의 직접 조작 또는 미술 품질 판정을 대신하지 않는다.

## 컴퓨터 사용 도구의 실제 OS 입력

`computer-use`의 창 선택·실제 마우스 클릭·키 입력으로 확인했다. 이 항목은 합성 `Input.parse_input_event` 실행과 구분한다. PNG는 해당 창의 입력 이후 Godot이 렌더한 화면이며, 사람 플레이 영상이라고 표기하지 않는다.

| 항목 | 결과와 조건 |
| --- | --- |
| 1440×960, 정상 속도 | 햇빛→오른쪽 큰 그늘→햇빛 이동, 입구 접근·입장→지도 클릭→대시보드→모의 계획 팝업→Esc 3단계 복귀. 같은 야영지 위치/방향 복원 확인. |
| 1440×960 대표 나무 경로 | 나무 왼쪽 위 지면에서 우측 아래 마당으로 이동. 나무 뒤에서 몸이 가려지고 우회 후 다시 나타나는 것을 확인. 기존 가림 다각형은 수정하지 않음. |
| 1440×960 창 전환 | 정상 속도 Alt+Tab 이탈 3회·복귀 2회. 도구의 다음 입력 전에 도착했으므로 **이동 중 정지 검증으로 계산하지 않음**. |
| 1280×720 이동 중 포커스 이탈 | 검수용 **0.25배**에서 보행 중 Alt+Tab. 목표 (653.59,369.14)에 도착하기 전 (798.10,526.61)에서 정지. 복귀 때 같은 좌표이고 이전 경로가 재개되지 않음. 새 클릭 정상 수신. |
| 1280×720 이동 중 목적지 변경 | 검수용 **0.25배**. 이전 목표 (1056.25,772.50)로 이동 중 (940.02,661.30)에서 새 목표 (1066.25,517.50) 클릭. 기존 경로를 바꾸고 새 그늘 위치에 도착. |

느린 재생은 도구의 약 10초 입력 간격보다 짧은 보행 구간을 관찰하기 위한 **테스트 실행 옵션**이다. 제품의 이동 속도·가감속·보행 값이나 프로젝트 설정은 변경하지 않았다. 정상 속도 이동 중 Alt+Tab과 사람의 직접 키보드·마우스 조작은 여전히 별도 확인 대상으로 남는다.

실제 시점·목적지·포커스·밝기 상태는 비교 폴더의 `native-1280.jsonl`, `native-1440.jsonl`에 기록했다. 1440 기록의 첫 ready 두 건은 별도 제한 환경 실행 후 데스크톱 실행을 시작한 흔적이다. 별도의 native 로그에서 실제 데스크톱 실행을 구별할 수 있다.

## 미술 한계

- 고정 배경의 **6개 주요 그늘 구역 근사**다. 작은 잎 그림자가 머리·몸·다리를 따로 가로지르는 정밀한 그림자 투영은 아니다. 발 주변의 햇빛 비율을 캐릭터 전체 조명에 적용한다.
- 배경 조명은 정적이다. 태양 이동, 시간대 변경, 바람에 따라 흔들리는 배경 그림자를 새로 구현하지 않았다.
- 코드로 제작한 얼굴·몸·장비는 여전히 사실적인 배경보다 단순하다. 망토 문양과 조명 일치는 개선했으나 시안의 인물 품질을 달성했다고 주장하지 않는다.
- 나무·상자 가림은 이전 대표 마스크를 유지한다. 작은 잎·복잡한 상자 모서리의 정밀도에는 한계가 있다.
- 1280×720 대시보드는 세로 스크롤을 사용한다. 사람 플레이·장시간 반복·다른 GPU/드라이버는 미검증이다.

## 재현

일반 게임은 `project.godot`를 열고 F5. 시작점에서 오른쪽 위 마당의 짙은 나무 그림자로 걸어간 뒤 밝은 중앙/아래 마당으로 돌아오면 밝기 전이를 확인할 수 있다.

```powershell
$godot = 'C:\Users\hanso\Tools\Godot\Godot_v4.7.2-stable_win64_console.exe'
& $godot --headless --path . --script res://tests/camp_lighting_test.gd
& $godot --path . --script res://tests/camp_lighting_test.gd
# OUTPUT에는 쓰기 가능한 절대 출력 폴더를 지정한다.
& $godot --path . --resolution 1440x960 --script res://tests/camp_lighting_review.gd -- after OUTPUT 1440
& $godot --path . --resolution 1280x720 --script res://tests/camp_lighting_review.gd -- native OUTPUT 1280
```

native의 F9는 검수용 시간 배율만 바꾼다. 보통 F5로 시작한 게임에는 이 단축키가 없다.
