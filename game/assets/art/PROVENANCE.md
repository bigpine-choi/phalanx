작성: 2026-09-28. 아래 세 PNG는 이번 구현 세션에서 내장 **OpenAI `image_gen`** 도구로 생성해 프로젝트에 적용한 파일이다. 외부 에셋 사이트에서 다운로드하거나 구매한 자산이 아니며, 이 제작을 위한 계정 생성·새 프로그램 설치는 없었다.

## 사용 방식과 한계

현재 장면은 생성한 고정 배경, 알파 캐릭터, 배경 일부를 다시 그리는 가림 마스크, 코드로 그리는 불꽃·먼지의 **2.5D 구성**이다. 전체 야영지나 사령부를 새 3D 모델로 제작했다고 해석하지 않는다. 원본 배경은 비율을 유지해 배치하고 이동·클릭·가림 좌표를 해당 구도에 맞춘다.

배경의 조명·천 주름·소품은 이미지에 포함된 정적인 표현이다. 캐릭터는 단일 포즈에 좌우 반전과 작은 보행 흔들림을 적용하며, 다방향 보행 프레임이나 리깅된 3D 모델이 아니다. 배경을 교체하면 경로·장애물·가림·클릭 영역과 효과 위치도 다시 맞춰야 한다.

이 기록은 생성 도구와 실제 적용 파일의 출처를 밝히는 문서다. 별도 외부 에셋의 CC0·CC-BY 라이선스를 부여하거나 독점성을 보장하는 기록이 아니다. 이전 제작 지침에 있던 외부 재질 후보를 이번 작업에 사용했다고 주장하지 않는다.

## 캐릭터 움직임 개선 추가 기록 · 2026-09-28

`quarter_camp.png`와 `headquarters.png`는 계속 사용하는 기존 생성 배경이다. **`commander.png`는 이전 단일 포즈 구현을 보존하는 파일이며 현재 야영지 캐릭터 런타임에서는 사용하지 않는다.** 위 단일 포즈·반전·흔들림 설명은 이전 단계에만 해당한다.

현재 지휘관은 프로젝트 안에서 코드로 제작한 관절형 3D 모델이다. 캐릭터 하나를 38도 사선의 고정 직교 카메라로 투명 뷰포트에 렌더한 뒤 기존 2D 배경에 합성한다. 배경이나 야영지 전체의 3D 재제작, 사전 렌더 스프라이트 시트 제작, 새 이미지 생성은 이번 캐릭터 작업에 포함되지 않는다.

| 적용 파일 | 제작 방식·용도 |
| --- | --- |
| `scripts/commander_model.gd` | 코드로 구성한 지휘관 모델·관절·리넨 갑옷·붉은 망토, 다리 IK와 팔·망토 포즈. |
| `scripts/commander_gait.gd` | 실제 이동 거리의 보행 위상, 발의 지면 기준점, 연속 방향과 대기·보행 전환. |
| `scripts/commander_visual.gd` | 캐릭터 전용 3D 조명·카메라·투명 렌더, 2D 배치와 접지/방향 그림자. |
| `scripts/camp_avatar.gd` | 기존 경로를 따르는 캐릭터 위치와 가감속. 표현 코드는 위 모듈에 위임. |
| `scripts/camp_foreground.gd`, `shaders/camp_foliage.gdshader` | 기존 배경에서 같은 UV로 다시 그리는 대표 나무·상자 윤곽과 제한된 식생 알파 처리. 별도 외부 이미지 사용 없음. |

새 캐릭터에 외부 모델·모션·텍스처 다운로드, 유료 구매, 계정 생성, 새 프로그램 설치는 사용하지 않았다. 새 파일에 외부 에셋 라이선스가 있다고 주장하지 않으며, 이 출처 기록 자체가 CC0·CC-BY 등 별도 라이선스를 부여하지 않는다. 동작 검사와 배경 합성의 실제 품질·한계는 [캐릭터 움직임 검증 기록](../../docs/AVATAR_MOTION_VALIDATION.md)에 별도로 기록한다.

## 그늘 반응·망토 후속 기록 · 2026-09-28

새 PNG/외부 모델/텍스처를 생성하거나 내려받지 않았다. `camp_light_field.gd`는 기존 배경의 주요 그림자를 원본 좌표 다각형으로 기술한 코드 데이터다. `commander_visual.gd`가 이에 맞춰 기존 모델의 실제 조명과 합성 그림자를 바꾼다. `commander_model.gd`의 태양 문양과 이중 옷단은 변형되는 망토 UV에 코드로 그린 것이며 외부 이미지가 아니다. 위 3개 PNG 해시는 그대로다. 제한과 검증 조건은 [그늘 반응 검증](../../docs/CAMP_LIGHTING_VALIDATION.md)에 기록했다.
