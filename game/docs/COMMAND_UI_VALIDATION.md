Godot 편집기에서 F5로 실행한 실제 게임 창에서도 마우스로 입구 이동 → 사령부 입장 → 작전 지도 열기를 확인했습니다. 큰 창에서 확대된 분석 UI를 확인하고, Godot 실행 화면(로컬 결과 폴더)을 남겼습니다.

리서치 캡처는 네트워크를 사용하지 않는 검증 모드입니다. 따라서 ‘일봉 자료 없음’ 표시가 있으며, 실제 시세 조회 장애를 뜻하지 않습니다.
