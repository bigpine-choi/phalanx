# 실계좌 시장 화면 · 2026-09-29

시장·리서치·포트폴리오를 같은 종목과 관측 자료로 연결했습니다. 기존 목재·청동·양피지 화면을 유지하면서 예시 지수·가격·차트를 실제 자료로 교체했습니다.

## 사용하는 순서

1. 야영지 → 사령부 → 작전 지도를 엽니다. 계좌와 선택한 종목의 일봉을 조회합니다.
2. 왼쪽 **보유 · 관심**에서 종목을 선택합니다. 전체 보유종목과 관심종목이 함께 표시되며 종목명·코드로 검색할 수 있습니다. `Ctrl+K`는 검색창으로 이동합니다.
3. 가운데에서 마지막 일봉 종가, 이전 일봉 대비 등락률, 거래량, 거래일·수신 시각을 확인합니다. **일봉 갱신**으로 다시 조회합니다.
4. 하단 **나의 배치**에서 해당 종목의 보유 수량·평가액·증권사 손익·주식 내 비중을 확인합니다.
5. **이 종목 비중 변경 →**는 포트폴리오의 해당 종목 입력란으로 이동합니다. 목표값은 자동으로 바꾸지 않습니다. 이후 변경안 계산 → 선택적 참모 검토 → 명령서 적용으로 진행합니다.
6. **종목 분석 · 참모 →**는 같은 종목의 리서치를 엽니다. **지표만 계산**은 기존 Python 계산만 실행하고, 브리핑·가설 반박·작전 검토는 기존 OpenAI 설정으로 요청합니다. 화면 이동 자체는 AI를 호출하지 않습니다.

**잔고 새로고침**은 시장과 포트폴리오가 함께 쓰는 계좌 자료를 갱신합니다. 기존 계산 결과는 무효화되며, 새 잔고로 현재 보유량 유지 상태에서 다시 시작합니다. 변경 중인 계획은 필요하면 먼저 명령서에 적용해 보관하세요.

## 숫자를 읽는 기준

| 표시 | 기준 |
| --- | --- |
| 상단 순자산·예수금·주식평가액·평가손익 | 증권사 계좌 요약의 조회 시점 값 |
| 왼쪽 보유종목 가격 | 잔고 조회 때 받은 가격. 마우스를 올리면 수신 시각 표시 |
| 왼쪽 비보유 관심종목 가격 | 조회한 마지막 일봉 종가. 아직 조회하지 않으면 `—` |
| 가운데 큰 가격·등락률 | 마지막 일봉 종가와 직전 일봉 종가의 비교 |
| 차트 | KRX 수정주가 일봉, 전일까지 최근 365일 요청. 실제 OHLCV와 거래일 |
| 하단 평가액·주식 내 비중 | 잔고 조회 가격 × 수량. 비중의 분모는 조회 주식 평가액이며 현금 제외 |
| 하단 증권사 손익 | 계좌 응답의 평가손익. 위 조회가로 새로 계산한 손익이 아님 |

계좌 조회가와 전일 일봉 종가는 기준 시점이 다릅니다. 당일 봉·실시간 스트리밍·시장 지수는 연결하지 않았습니다. 예수금은 주문가능금액이 아니며 시뮬레이션에는 별도 현금 가정을 사용합니다. 현재 시뮬레이터는 보유종목의 배분 변경을 지원하고, 미보유 종목의 신규 편입과 실제 주문은 연결하지 않았습니다.

삼성전자 공식 연간 재무 확인본을 유지합니다. 공시 연결이 없는 종목은 재무 자료 없음으로 표시하며, 다른 회사 수치를 대신 표시하지 않습니다.

## 저장·오류·Python 연결

- 시장과 리서치는 하나의 일봉 조회·캐시를 공유합니다. 빠른 종목 전환 후 늦게 도착한 응답은 현재 종목에 표시하지 않습니다.
- 조회 전·실패·자료 없음에는 가짜 값이나 0원을 만들지 않습니다. 이전 정상 자료가 있으면 시각과 실패 상태를 표시합니다. 잔고 재조회 실패 시 이전 잔고로 새 비중 계획을 만들 수 없습니다.
- 관심 등록한 새 종목의 코드·이름과 메모를 저장합니다. 실행 중 관측한 원본 잔고는 새 프로필 필드로 저장하지 않습니다. 명령서에 적용한 계획과 봉인 기록의 기존 저장 방식은 유지합니다.
- 기존 WSL `production_history_reader`와 계좌 조회 서비스를 그대로 재사용합니다. Godot 어댑터의 종목 제한을 고정 5개에서 검증된 6자리 대문자·숫자 코드로 확장했습니다. 원본 Python 저장소는 수정하지 않았습니다.
- 참모의 수치 계산은 기존 Windows Python의 수익률·변동성·낙폭 계산을 재사용합니다. 시장 잔고 금액·수량·계좌번호를 종목 참모 입력에 추가하지 않았습니다. 종목명·자료·노트·적용된 계획의 제한된 비중 정보는 기존 요청 버튼으로 전송합니다.
- 낮은 창에서는 상단 계좌 요약 카드를 접어 차트와 하단 행동 버튼 공간을 확보합니다. 계좌 요약은 포트폴리오에서 계속 볼 수 있습니다. 더 작은 게임 내부 지도에서는 가운데 차트·보유 현황 영역을 스크롤하며, 하단 상태 표시줄과 겹치지 않습니다.
