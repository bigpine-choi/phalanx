# 연구 배분 게임 연결 검증 · 2026-10-01

## 범위

Godot 4.7.2 소스 프로젝트의 사령부 **Ⅳ 연구 배분** 화면에서 저장된 `allocation-targets` JSON을 연다. Python 표시 파서는 파일의 구조·표시 관계를 검사하고 게임에 필요한 작은 결과만 넘긴다. 이 경로는 원천 SQLite DB·영수증을 다시 열지 않으며 실계좌·모의 계획·주문에 배분을 적용하지 않는다.

검사 자료 `tests/fixtures/synthetic_research_allocation_targets.json`은 합성 종목 여섯 개·504개 수익률 관측으로 실제 위험모형과 ERC 계산 코드를 실행해 만들었다. 네 비중 결과는 계산 코드 산출물이고, 재실행 SHA 값은 형식에 맞춘 **합성 자리값**이다. 따라서 이 검사는 게임의 파일 읽기와 화면 표시를 증명하며 영수증의 진위를 증명하지 않는다. PR #32의 실제 SQLite·읽기 영수증 재검증은 Linux Python 검사 범위다.

## 실행 결과

| 실행 | 결과 |
| --- | --- |
| `research_allocation_test.gd` headless | 32개 검사 통과 |
| 같은 테스트, Windows D3D12 GUI | 34개 검사 통과, 1440×960 캡처 확인 |
| `terminal_workspace_test.gd` | 40개 검사 통과 |
| `portfolio_test.gd` | 41개 검사 통과 |
| `quarter_flow_test.gd` | 202개 검사 통과 |
| `smoke_test.gd` | 통과 |

새 테스트는 실제 사령부 씬에서 네 번째 탭을 열고, 저장 파일→Windows Python 브리지→Godot 화면을 통과시킨다. 네 시나리오 전환, 잘못된 파일의 이전 비중 제거, 누락 파일 거부, 파일 선택 신호를 통한 다시 열기, 실계좌 계획과의 분리, 900×680·1280×720·1440×960의 가로 넘침 방지를 확인한다. GUI 검사에서는 NVIDIA D3D12 렌더러로 창을 띄워 화면을 캡처하고 글자·탭·시나리오 행을 눈으로 확인했다. 테스트 입력은 합성이며 운영체제 파일 선택창에서 사람이 직접 경로를 고른 검사는 아니다.

게임이 열리는 소스 체크아웃에 Windows Python 실행 환경이 필요하다. 내보낸 단독 실행 파일의 Python 브리지 패키징은 이 검증에 포함하지 않는다. 게임 실행 중 Windows 루트 인증서 저장소 경고가 출력됐지만 로컬 파일 화면 검사와 테스트 종료 상태에는 영향을 주지 않았다.
