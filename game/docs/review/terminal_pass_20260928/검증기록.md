# Phalanx 투자 워크스페이스 · 첫 UI 패스

2026-09-28. 사용자가 선택한 **MTS의 명료함 + 터미널의 정보 밀도**를 기존 Godot 투자 화면에 적용했다. 게임 미술은 이번 작업에서 변경하지 않았다. 실시간 데이터·계좌·실제 주문은 연결하지 않았다.

## 구현 결과

- **시장:** 검색 가능한 관심종목, 지수 요약과 작은 추세 그래프, 계좌 요약, 캔들/라인 차트, 1개월·3개월·1년, 20일 평균, 포인터 기준 OHLC와 교차선.
- **포트폴리오:** 보유액·손익·현재/목표 비중을 한 표에 표시. 종목을 선택하면 공통 비중 계획에 연결한다. 기존 가상 계좌 계산과 비중 합계 검증을 보존했다.
- **리서치:** 선택 종목의 예시 근거·위험·점수, 종목별 임시 메모. 종목/화면 변경과 사령부 재진입에도 실행 중인 메모를 유지한다. 앱 종료 후에는 저장하지 않으며 화면에 이를 명시한다.
- **시각 체계:** 짙은 회청색 바탕, 민트·로즈 등락, 금색 강조, 정렬된 숫자, 작은 테두리와 일정한 여백. PHALANX 자체 UI이며 Bloomberg의 서비스나 데이터에 연결하지 않는다.
- **작은 창:** 시장 화면은 전체 세로 스크롤 없이 차트와 기간 조작을 유지한다. 비중 계획의 검토 버튼은 하단에 고정하고 세부 정보만 스크롤한다. 더 좁은 화면은 비중 계획을 포트폴리오로 옮긴다. 포트폴리오와 리서치의 긴 내용은 개별 세로 스크롤을 사용한다.

| 실제 OS 창 조작 | **1280×720**. 컴퓨터 사용 도구로 SK하이닉스 선택, 라인/1개월 전환, 목표 16→16.5%, 포트폴리오 표시, 리서치 한국어 입력, Ctrl+K 검색·코드 005930·Enter, 모의 계획, Esc 팝업→대시보드 순차 닫기, 지도 재진입, 종목별 메모 복원 확인 |
| 사람의 직접 조작 | 이번 결과로 별도 검증하지 않음. 1440×960 OS 조작과 이번 UI의 Alt+Tab 반복도 별도로 검증하지 않음 |

차트가 매 프레임 임시 글꼴을 생성해 축 문자가 깨지는 렌더 문제를 발견했고, 글꼴 리소스를 차트 수명 동안 유지하도록 수정했다. 최종 GPU 캡처에서 정상 숫자를 확인했다. 자동 실행 환경에서는 Windows 인증서 저장소 읽기 오류가 출력됐으나 테스트는 정상 종료했다. 실제 데스크톱 실행 로그에는 해당 오류가 없었다.

## 변경 파일

- `scripts/headquarters.gd`: 시장/포트폴리오/리서치와 공통 선택·입력 상태, 반응형 배치.
- `scripts/price_chart.gd`: 차트 스타일, 라인 모드, 교차선, 축·OHLC 표시.
- `scripts/dashboard_overlay.gd`: 공통 테마와 좁은 헤더/여백. 기존 팝업 우선 Esc 유지.
- 새 `scripts/terminal_theme.gd`, `terminal_sparkline.gd`, `terminal_fixtures.gd`: 스타일·작은 차트·가상 지수 분리.
- `tests/smoke_test.gd`, `quarter_flow_test.gd`: 새 배치에 맞춰 가시성/스크롤 검사 갱신.
- 새 `tests/terminal_workspace_test.gd`, `terminal_review.gd`: 워크스페이스 회귀와 GPU/실제 창 검수 준비.
- `README.md`, `docs/SESSION_HANDOFF.md`, `docs/TERMINAL_UI_VALIDATION.md`: 현재 개발 초점과 검증 기록.

`scripts/demo_data.gd`는 작업 시작 사본과 동일하다. 가상 가격·계좌·수량 계산은 수정하지 않았다. 브랜치 `feature/camp-art-pass-b`, HEAD `344b8aa`를 유지하며 commit·merge·push·stage·reset은 수행하지 않았다.

## 실행과 다음 개발

Godot에서 기존 `project.godot`를 열고 F5. 사령부 지도에서 투자 화면을 연다. UI만 보려면 `scenes/headquarters.tscn`을 열고 F6.

이번 결과는 데스크톱 투자 UI의 첫 패스다. 모바일 MTS 앱, 실시간 전문 터미널, 서버 저장은 아직 구현하지 않았다. 다음 우선순위는 **관심종목·리서치 노트 영구 저장 → 실제 투자엔진의 데이터 계약과 연결 → 비교·필터·알림**이다. 먼저 사용자가 자주 하는 투자 판단 흐름을 이 화면에서 완결하는 데 집중한다.
