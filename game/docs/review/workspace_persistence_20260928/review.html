관심목록 복원

종목별 노트 복원

종료 직전에 입력한 SK하이닉스 노트가 새 프로세스에서도 그대로 표시됩니다. 노트는 화면 이동·관심 해제와 독립적으로 유지됩니다.

위 이미지는 자동으로 상태를 준비한 실제 GPU 렌더입니다. 별도로 1280×720 실제 Windows 창에서 관심 해제·한국어 입력·정상 종료·재실행 복원을 컴퓨터 사용 도구로 확인했습니다. 모든 금융 값은 가상 데이터입니다.
